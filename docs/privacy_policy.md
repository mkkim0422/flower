# 잘자라라 개인정보 처리방침

시행일: 2026-__-__ (스토어 출시일에 맞춰 확정)
운영자: (사업자명 또는 개인 이름) · 문의: (이메일)

잘자라라(이하 "앱")는 사용자의 식물 관리 기록을 돕는 앱입니다. 앱은 **로그인 없이** 사용할 수 있으며, 아래에 적은 경우를 제외하고 어떤 정보도 서버로 보내거나 보관하지 않습니다.

## 1. 기기에만 저장되는 정보

다음 정보는 사용자의 기기 안에만 저장되며 운영자는 접근할 수 없습니다.

- 등록한 식물 정보(이름, 품종, 물 준 날, 물주기 설정, 메모)
- 생장 일기(사진, 메모, 상태 태그)
- 식물 사진(촬영 또는 앨범에서 선택한 사진의 축소본)
- 알림 시간·요일 설정, 화면 표시 설정
- 사진 식별 이력(식별에 사용한 사진의 기기 내 경로와 후보 목록)

앱을 삭제하면 위 정보는 모두 함께 삭제됩니다.

## 2. 외부로 전송되는 정보

### 2-1. 사진 식별 (Pl@ntNet)

사용자가 "사진으로 식별" 기능을 사용할 때에 한해, 선택한 사진을 1024px 이하로 축소하고 **위치 정보 등 메타데이터(EXIF)를 제거한 뒤** 식물 식별 서비스 Pl@ntNet(my-api.plantnet.org, 프랑스)에 전송합니다.

- 전송 목적: 사진 속 식물의 품종 후보를 받기 위해
- 전송 항목: 축소·메타데이터 제거된 사진(한 번에 최대 5장)
- 운영자 보관: **하지 않습니다.** 앱은 응답을 받은 뒤 전송한 사진을 서버에 남기지 않으며, 운영자는 사진을 받거나 볼 수 없습니다.
- 수신자 측 처리: Pl@ntNet의 개인정보 처리방침(https://plantnet.org/privacy)을 따릅니다.
- 이름 검색이나 직접 입력으로 등록하면 사진은 어디에도 전송되지 않습니다.

### 2-2. 백업 (서버 없음)

앱에는 로그인과 운영자 서버가 없습니다. 기록을 옮기는 방법은 두 가지이며, 둘 다 운영자가 볼 수 없습니다.

- **파일 내보내기·가져오기**: MY › 백업에서 기록과 사진을 zip 파일 하나로 만들어, 사용자가 고른 곳(내 드라이브, 메신저 등)에 직접 저장합니다. 파일을 어디에 둘지는 사용자가 정합니다.
- **기기 자동 백업**: Android 기기 설정에서 백업이 켜져 있으면 운영체제가 앱 기록(사진 제외)을 사용자의 Google 계정에 백업하고, 새 기기로 옮길 때 복원합니다. iPhone은 iCloud 기기 백업 설정을 따릅니다.

## 3. 사용 권한

| 권한 | 용도 | 요청 시점 |
|---|---|---|
| 카메라 | 식물 사진 촬영(식별·일기) | 카메라 기능을 처음 사용할 때 |
| 사진·미디어 | 앨범에서 식물 사진 선택 | 앨범 기능을 처음 사용할 때 |
| 알림 | 물 주는 날 알림 | 첫 실행 안내 화면에서(거절 가능) |

영어 버전: [privacy_policy_en.md](privacy_policy_en.md)

권한을 거절해도 해당 기능 외의 앱 사용에는 제한이 없습니다.

## 4. 수집하지 않는 정보

- 위치 정보, 연락처, 광고 식별자
- 이용 행태 분석·추적 (분석 도구를 사용하지 않습니다)
- 결제 정보 (앱 내 결제·구독·광고가 없습니다)

## 5. 기록 삭제

운영자 서버에 저장되는 기록이 없으므로 계정 삭제 절차가 없습니다. 앱을 삭제하면 기기의 기록이 모두 지워집니다. 내보낸 백업 파일은 사용자가 직접 지우면 됩니다.

## 6. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

## 7. 방침 변경

방침이 바뀌면 앱 안의 이 페이지와 스토어 설명에 변경 사항과 시행일을 알립니다.
