# 스토어 등록 초안 (Play Store · App Store)

영어 버전: [store_listing_en.md](store_listing_en.md)

> 확정 전 초안. 앱 이름·패키지명·처리방침 URL이 정해지면 채운다.

## 공통

- 앱 이름: **잘자라라**
- 부제(App Store 30자): 물 주는 날을 알려주는 식물 다이어리
- 짧은 설명(Play 80자): 사진 한 장으로 품종을 찾고, 물 주는 날을 알려드려요. 로그인·광고 없음.
- 카테고리: 라이프스타일 (Play: Lifestyle / App Store: Lifestyle)
- 연령 등급: 전체 이용가 (Play 설문: 폭력·성·약물 없음 / App Store 4+)
- 개인정보 처리방침 URL: (GitHub Pages) https://<계정>.github.io/jaljarara/privacy_policy
- 가격: 무료, 인앱 결제 없음, 광고 없음

## 전체 설명

집에 있는 식물, 언제 물을 줬는지 기억나지 않으시죠. 잘자라라는 딱 그것만 해결해요.

**사진 한 장으로 품종 찾기**
잎이나 꽃을 찍으면 어떤 식물인지 후보를 보여드려요. 이름으로 검색해도 되고, 몰라도 그냥 이름만 붙여 등록할 수 있어요.

**물 주는 날 D-day**
품종과 계절에 맞는 주기를 계산해서 홈 화면에 D-day로 보여드려요. 물을 줬으면 "물 줬어요" 한 번. 다음 날짜가 바로 잡혀요.

**매일 한 번, 알림 한 개**
정해진 시간에 "오늘 물 줄 식물이 N개 있어요" 한 줄만 보내드려요. 알림이 쌓이지 않아요.

**메모와 일기**
놓은 자리, 산 날, 잎 상태를 메모로 남기고, 사진과 함께 자라는 모습을 기록해요.

**알아두면 좋은 정보**
독성(반려동물·아이), 빛, 온도, 흔한 문제를 품종별로 정리해 드려요. 국내에서 많이 키우는 540여 종을 담았어요.

**로그인도, 광고도 없어요**
기록은 기기에만 저장돼요. 폰을 바꿀 때는 백업 파일로 옮기면 돼요.

## 스크린샷 구성 (6.7인치 기준 5~6장)

1. 홈 — 앨범형 카드와 D-day
2. 사진 식별 결과 — 후보 목록
3. 식물 상세 — D-day, 내 메모, 알아두면 좋은 정보
4. "물 줬어요" 바텀시트
5. 일기 작성
6. 도감 페이지 — 독성 배지

## 스토어별 필수 항목

### Google Play
- 앱 서명: Play App Signing 사용, 업로드 키는 `android/key.properties`(로컬)
- 데이터 보안 양식: 수집 데이터 "없음" 선택. 단, 사진 식별 시 사진이 제3자(Pl@ntNet)로 전송되지만 저장되지 않음 → "일시 처리"로 기재하고 처리방침에 명시(처리방침 2-1)
- 광고 ID 사용: 아니오
- 타겟 API: Flutter 기본(targetSdk 최신) 유지
- 계정 삭제 URL: 백업 로그인 제공 시 필요 → 앱 내 MY › 계정 › 탈퇴 + 처리방침 5장 링크

### App Store
- Sign in with Apple: 소셜 로그인(Google) 제공 시 필수 → AUTH-01에 포함
- App Privacy: "데이터 수집 안 함" 선택 가능 여부 검토. 백업 로그인 시 계정 식별자·이메일 수집 → "사용자에게 연결된 데이터: 식별자, 연락처 정보(이메일)" 최소 기재
- 계정 삭제: 앱 내 제공 필수(MY-04)
- 수출 규정: `ITSAppUsesNonExemptEncryption=false` (Info.plist 반영됨)
- 심사 메모: PlantNet API 키는 심사용 빌드에 포함, 테스트용 식물 사진 첨부
